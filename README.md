# Portfolio Website

## Overview
A responsive personal portfolio website with a modern Neon UI / glassmorphism design.

## Sections
- Home
- About
- Skills & Tech
- Projects
- Internships
- Education
- Contact

## Skills & Tech
The Skills & Tech section includes:
- Frontend: HTML, CSS, JavaScript, React.js
- Backend: Java, Python, C, Spring Boot
- Database: MySQL
- Tools & Technologies: Git, GitHub, VS Code, Docker, Postman
- AI Tools: ChatGPT, GitHub Copilot, Google Gemini, Claude, Microsoft Copilot

## Design
- Responsive for desktop and mobile
- Neon cyan glow styling
- Glassmorphism cards
- Technology logos with original-style colors
- Smooth hover effects

## Run Locally
Open `index.html` in a browser, or use a local development server such as VS Code Live Server.

## Customization
Update the HTML, CSS, JavaScript, and image files to customize personal information, projects, profile photo, and links.
